# 风险登记与时间预算

配套主文档 §8、§11。

## 风险表

| 风险 | 影响 | 概率 | 缓解措施 |
| --- | --- | --- | --- |
| 分区界面误删**数据分区** | 该分区上全部数据不可恢复 | 中 | 只按容量+卷标识别且以 Step 0 快照为准；P0 先外备 |
| 装后无线无法联网 | 无法下载驱动/激活 | 低 | 按目标机器网卡型号准备离线驱动；准备备用联网方式 |
| 数字许可证未自动激活 | 系统未激活 | 低 | 登录原微软账号走激活疑难解答 |
| iNode/Horizon 需 IT 重新授权 | 短期无法接入内网 | 中 | 重装前向 IT 确认安装包与审批流程 |
| 家庭版强制联网 OOBE | 无法创建纯本地账号 | 中 | 接受微软账号登录 |
| 安装途中掉电 | 分区表损坏 | 低 | 全程插电，电量保持 100% |
| **安全启动关闭后未恢复** | 安全特性受限，可能影响依赖 Secure Boot 的功能 | 低 | 如曾关闭，装完进 BIOS 重新开启并验证；路径与命令见 `references/07-bios.md` |
| **`C:\Windows.old` 残留** | 占用系统盘空间 | 常见 | 设置 → 系统 → 存储 → 临时文件 → 删除「以前的 Windows 安装」，勿手动删 |

## 时间预算

> 以下是规划时间范围；实际耗时取决于网络、备份量、设备和 IT 审批。

| 阶段 | 预计耗时 |
| --- | --- |
| 备份（P0 外备 + 大批量到 D 盘） | 1–2 小时 |
| 制作安装 U 盘 + 下载驱动 | 0.5–1 小时 |
| 系统安装 | 0.5–1 小时 |
| 驱动、激活、系统更新 | 0.5–1 小时 |
| 软件恢复 | 1–2 小时 |
| 配置与企业软件恢复 | 1–2 小时（受 IT 审批影响） |

建议安排在完整工作日或周末，**留出重装后无法立即接入内网（iNode/Horizon）的缓冲**。
